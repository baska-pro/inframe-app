# Support

Sebelum membuat issue:

1. Baca README dan bagian Troubleshooting.
2. Pastikan deployment GAS terbaru sudah aktif.
3. Pastikan GAS menggunakan `XFrameOptionsMode.ALLOWALL` jika dibungkus dalam iframe.
4. Uji target langsung di tab browser.
5. Coba `?frameOffset=0` untuk memastikan masalah bukan akibat crop banner.
6. Jangan kirim `.env`, token, cookie, atau data sensitif.

Gunakan **Bug report** untuk masalah yang dapat direproduksi dan **Feature request** untuk usulan peningkatan.
