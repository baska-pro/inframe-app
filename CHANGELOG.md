# Changelog

## 1.0.0 - 2026-09-10

### Added
- Universal target URL configuration through Vite environment variables.
- Google Apps Script auto-crop mode for the visible information banner.
- Query parameter forwarding to the wrapped application.
- Optional runtime URL override protected by a host allowlist.
- Generic responsive loader, retry flow, and external-open fallback.
- Vercel configuration, CI workflow, favicon, repository banner, and full setup documentation.

### Changed
- Removed KOMIDA-specific branding and hard-coded target URL.
- Removed unused Gemini environment configuration and AI Studio import-map dependencies.
- Replaced Tailwind CDN dependency with local production CSS.
